One funny passive-aggressive note a smart fridge leaves for its owner: a single line, dry, petty and specific, written deterministically to `/output/entry.txt` by `main.ts` (Node 22, standard library only, no network).

The entry (90 characters, one line):

> My sensors say your leftovers have been here nine days. I have started charging them rent.

Running `main.ts` twice produces byte-identical output. The program respects `MAKEFUN_OUTPUT_DIR` (default `/output`) and writes the line with no trailing newline, so the file is exactly the entry.

## Run it

```sh
node main.ts
```
